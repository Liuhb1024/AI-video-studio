6 个开源 AI 短漫剧系统：可迁移设计雷达

不是照搬代码，而是提炼“生产系统设计点”，迁移到 AI 英歌漫剧生产工作台。

LumenX

最值得学：清晰 SOP。

  • 资产提取 → 风格定调 → 资产生成 → 分镜脚本 → 分镜图 → 分镜视频
  • 角色先生成全身图，再生成三视图/头像特写
  • 每个分镜可选择角色、场景、道具参考图
  • 视频阶段支持多 batch 抽卡和最终选择

Toonflow

最值得学：Agent 分层和阶段质量门。

  • 决策层 / 执行层 / 监督层
  • 六阶段流水线：衍生资产 → 资产生成 → 导演规划 → 分镜表 → 面板 → 分镜图
  • 导演规划、分镜表需要审核
  • 只允许使用资产库真实存在资产

LocalMiniDrama

最值得学：本地生产体验和断点补全。

  • 一键生成 + 补全并生成
  • 失败自动重试
  • 实时进度 + 错误日志
  • 经典分镜 / 全能模式，支持 @图片1 多参考编排

Huobao Drama

最值得学：Agent Skill 文件化和分镜字段规范。

  • script_rewriter / extractor / storyboard_breaker / voice_assigner / grid_prompt_generator
  • 分镜要求 image_prompt / video_prompt / bgm / sound effect
  • video_prompt 按 0-3 秒、3-6 秒分段
  • 宫格图提示词要求 exactly N panels，防漏格/合格

waoowaoo

最值得学：prompt 资产分区。

  • lib/prompts 下有 character-reference / novel-promotion / skills
  • 提示词不是散写在代码里，而是作为生产资产组织
  • 适合我们后面做“提示词模板库”

FastMovieAI

最值得学：平台化外围能力。

  • 用户、积分、支付、插件、WebSocket 推送
  • 对 MVP 暂时不重要
  • 但任务进度推送和插件式模型配置可后置吸收

迁移到我们系统的优先级

P0

任务流 + 断点补全 + 可追溯

角色生图任务流先做成“可恢复、可重试、可追踪”。这是 LocalMiniDrama + LumenX 的共同强项。

P1

生产 Skill / Prompt 模板化

借鉴 Toonflow / Huobao / waoowaoo，把剧本、分镜、角色图、宫格图、视频提示词全部变成可编辑模板。

P2

监督层质量门

导演规划、分镜表、关键帧采纳前加入 AI 检查，但先别过早复杂化。

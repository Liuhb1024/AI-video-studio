AI 英歌漫剧生产链路：角色资产如何服务关键帧与视频

先看大图：我们不是做散装生图工具，而是在搭“可复用角色 IP 资产 -> 分镜关键帧 -> 视频片段”的生产流水线。

Production Map

1. 参考输入层

人工确定，不轻易污染。

  • 脸谱单图：角色硬锚点
  • 真人妆照四面：服饰/体态/道具
  • 角色文字设定：性格/武器/禁忌
  • 全局风格模板：画风约束

2. 角色生图任务层

一次生成 = 一条可追溯任务。

  • 生成类型：三视图/四视图/重绘
  • 模型：Seedream / nano banana / gpt-image
  • 输入：参考图 + 风格模板 + prompt
  • 输出：任务状态 + 结果图

3. 生成资产区

AI 结果先隔离存放。

  • 三视图 / 四视图
  • 风格转换图
  • 表情表 / 动作姿态
  • 服饰拆解 / 武器道具
↓ 人工挑选，避免劣质图进入生产主链路

4. 已采纳资产

真正可复用的角色视觉标准。

  • 可用于关键帧
  • 角色标准图
  • 风格基准图
  • 质量备注 / 版本

5. 分镜关键帧

分镜卡调用已采纳资产。

  • 镜头描述 + 景别 + 构图
  • 角色资产 + 风格模板
  • 生成关键帧图片
  • 多版本对比

6. 视频片段

关键帧驱动生视频。

  • 关键帧 + 运镜
  • 动作节奏 + 时长
  • 视频模型任务
  • 最佳版本归档

当前下一步建议

A

先做角色生图任务流

推荐。先让“发起生成”变成可追溯任务，模型先 mock，后续再接真实模型。

B

先做风格 AI 识别

让风格模板更聪明，但暂时还不能把角色图生产跑起来。

C

先做采纳机制

适合已有很多生成图时做；现在没有真实任务流，稍微早一点。

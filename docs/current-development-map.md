# AI 英歌漫剧生产工作台当前开发地图

更新时间：2026-05-09

## 0. 协作流程

项目采用“指挥官线程 + 功能开发线程”的协作方式。

- 指挥官线程维护总开发地图、决定下一模块、创建功能任务档案、接收完成记录。
- 功能开发线程只负责一个明确功能，完成开发、测试、用户验收和完成记录后关闭。
- 单功能任务档案保存在 `docs/features/`。
- 协作规则见 `docs/development-workflow.md`。

最近完成的功能任务档案：

- `docs/features/2026-05-08-async-generate-task-queue.md`
- `docs/features/2026-05-08-gpt-image-2-image-edit.md`
- `docs/features/2026-05-08-character-image-prompts-optimization.md`
- `docs/features/2026-05-09-project-character-linking.md`

下一阶段建议筹备：

- 场景中心设计探索：`docs/features/2026-05-09-scene-center-design.md`
- 分镜卡绑定项目角色
- 后续筹备关键帧生成任务档案
- 可选小修：仅在用户提供新的角色出图反馈或 prompt 范例时，局部调整角色生图提示词

## 1. 当前一句话状态

项目已经完成 MVP 骨架、项目/剧本/分镜/角色中心的主要前端体验、项目角色引用层、角色生图链路的真实闭环、GenerateTask 异步队列 MVP、GPT Image 2 图片编辑接入，以及角色中心生图提示词优化。

当前主线处在：

```text
角色参考图 + 全局风格模板 + Prompt
  ↓
选择任务：角色定稿 / 四视图
  ↓
选择模型：nano banana 2 / GPT Image 2 / Seedream 5.0 Lite
  ↓
GenerateTask
  ↓
异步队列 worker
  ↓
真实生图模型
  ↓
候选生成资产
  ↓
人工采纳 / 标废
  ↓
采纳资产供后续关键帧使用
```

下一条关键主线是：

```text
分镜卡 + 采纳角色资产 + 全局风格模板
  ↓
关键帧生成
  ↓
关键帧候选资产
  ↓
人工采纳
  ↓
生视频任务
```

## 2. 已完成模块

### 2.1 基础工程

- Next.js 前端骨架已建立。
- FastAPI 后端骨架已建立。
- PostgreSQL 数据模型已建立。
- 腾讯 COS 上传已接入。
- DMXAPI 文本/图像模型调用已接入部分模块。
- 工作台整体视觉方向已确定：暗色英歌片场后台风格。

### 2.2 项目中心

- 项目列表页。
- 创建项目。
- 删除项目。
- 项目文件夹式详情页。
- 项目内模块入口：剧本、分镜、角色、生成、素材、成片。
- 项目角色文件夹已接入全局角色引用。
- 项目内可搜索/选择全局角色，保存项目内身份、用途备注和状态。
- 项目角色数量已在项目详情页显示真实计数。

当前问题：

- 项目级数据联动还浅。
- 项目角色尚未绑定到分镜卡。
- 项目内素材、任务还未完全绑定成真实生产链。

### 2.3 剧本工作台

- 项目内剧本页面已做。
- 支持输入故事灵感。
- 支持选择参数：时长、平台、比例、故事结构、开头方式、结尾方式、情绪、英歌强度等。
- 接入 DMXAPI 大模型生成短视频剧本。
- 剧本输出包含时间段、剧情推进、场次拆分、画面重点、转分镜建议。
- 历史版本可查看、可删除。
- 生成后可进入分镜。

当前问题：

- 剧本版本还没形成“定稿/草稿/候选”的质量门。
- 剧本中的角色、场景、道具提取还未独立资产化。

### 2.4 分镜工作台

- 项目内分镜页面已做。
- 可选择剧本。
- 可从剧本生成分镜草案。
- 分镜卡包含镜头描述、角色、场景、情绪、动作、景别、构图、运镜、生图提示词、生视频提示词等字段。
- 支持基础分镜工作台 UI。
- 已开始按“分镜卡是生产中枢”设计。

当前问题：

- 分镜生成质量还需要继续优化。
- 分镜卡还未深度绑定角色资产、风格模板、关键帧候选资产。
- 分镜到关键帧链路还未开发。

### 2.5 角色中心

- 角色列表页。
- 角色详情页。
- 已导入英歌水浒角色基础资产。
- 每个角色有设定信息、英歌视觉信息、提示词资产。
- 支持角色参考图库。
- 支持角色定稿候选生成。
- 支持四视图 Prompt Draft 和固定版式四视图生成。
- 支持参考图配色保真契约。
- 角色中心生图提示词优化已完成，后续只按实际出图反馈局部小修。

参考图库已支持：

- 脸谱参考图：单图化。
- 真人妆照四面：
  - 真人全身正面
  - 真人半侧身（1）
  - 真人半侧身（2）
  - 真人背后
- 上传、预览、替换、删除。
- 回收站恢复。
- COS 存文件，数据库存链接和元信息。

当前问题：

- 角色新增/编辑仍需继续完善。
- 角色资产质量门还可加强，例如主参考选择、完整度评分。
- `three_view_prompt` 字段名仍与四视图产品目标不一致，暂未迁移。

### 2.6 全局风格模板库

- 已从角色中心抽离成全局共用库。
- 支持上传漫剧风格截图。
- 支持 AI 风格识别。
- 识别模型：gpt-5.4-nano。
- 温度：1.0。
- 识别失败不 fallback，直接记录失败。
- 风格识别任务落 GenerateTask。
- 已基于研究文档升级识别 prompt。

当前问题：

- 识别结果还需要更多实际样本打磨词汇库。
- 风格模板还未完全接入项目级默认风格。

### 2.7 角色生图工作台

- 抽屉式 UI。
- 支持选择生成目标：
  - 角色形象定稿
  - 角色四视图生成
- 支持选择参考图。
- 支持本地上传参考图。
- 支持选择全局风格模板。
- 支持编辑 Prompt / 负面 Prompt。
- 支持生成/优化 Prompt。
- 支持发起 GenerateTask。
- 支持展示任务进度。
- 支持展示本次生成结果。
- 支持采纳、标废、质量备注。
- 支持将采纳候选纳入角色参考图库。

已接入真实模型：

- DMXAPI `gemini-3.1-flash-image-preview`
- 页面名：nano banana 2
- DMXAPI `gpt-image-2-ssvip`
- 页面名：GPT Image 2
- DMXAPI `doubao-seedream-5.0-lite`
- 页面名：Seedream 5.0 Lite

已支持输出比例：

- `1:1`
- `16:9`
- `9:16`
- `4:3`
- `3:4`
- `3:2`
- `2:3`
- `21:9`

已支持等级：

- `1K`
- `2K`
- `4K`

预留模型：

- gemini-2.5-flash-image
- gemini-3-pro-image-preview

当前问题：

- 当前已接入 GenerateTask 异步队列 MVP，前端继续轮询任务状态。
- 队列仍是单进程内存队列，服务重启后尚未自动恢复未消费任务。
- `three_view_prompt` 字段名仍与四视图产品目标不一致，暂未迁移。
- 多用户/权限未做。

### 2.8 GenerateTask

已支持：

- 任务类型记录。
- 模型记录。
- 输入资产快照。
- prompt 记录。
- 参数记录。
- 输出资产记录。
- 错误记录。
- 失败重试。
- retry_of_task_id。
- 创建/重试接口立即返回 `queued`。
- 进程内 FIFO worker 执行角色生图任务。
- 执行中更新 `running`、`progress`、`current_step`。
- 成功后回填 Asset 和 `output_asset_ids`。
- 失败后记录 `error_code` 和 `error_message`。

已完成任务档案：

- `docs/features/2026-05-08-async-generate-task-queue.md`
- `docs/features/2026-05-08-gpt-image-2-image-edit.md`
- `docs/features/2026-05-08-character-image-prompts-optimization.md`

当前问题：

- 当前队列是单进程内存 MVP，服务重启后不会自动恢复内存中未消费的队列项。
- worker 与 API 进程同生命周期，还不是独立进程或外部 broker。
- 还没有统一任务中心页面的详细可视化。
- 成本统计还未贯通。

## 5. 推荐开发顺序

### P0-1：任务地基

状态：已完成异步 GenerateTask 队列 MVP。

后续补强：

1. 启动恢复 `queued/running` 陈旧任务。
2. 统一任务详情抽屉/页面。
3. 成本记录字段接入。

原因：

后面关键帧和视频都会依赖任务系统。先把地基打稳，少返工。

### P0-2：做关键帧生成

1. 分镜卡选择。
2. 读取采纳角色资产。
3. 读取全局风格模板。
4. 组装关键帧 Prompt。
5. 创建关键帧 GenerateTask。
6. 输出关键帧候选区。
7. 人工采纳/标废。

原因：

关键帧是从“角色资产”走向“分镜生产”的第一座桥。

### P0-3：完善分镜卡中枢

1. 分镜卡绑定角色资产。
2. 分镜卡绑定关键帧。
3. 分镜卡生成 Prompt 可编辑。
4. 分镜卡状态流转。

原因：

系统最终生产单元是分镜卡，不是角色中心。

### P0-4：生视频生成

1. 从已采纳关键帧发起视频任务。
2. 生视频 Prompt 生成。
3. 视频候选区。
4. 多版本对比。
5. 选择最佳版本。

### P0-5：素材库 / 成片归档 / 看板

1. 素材统一检索。
2. 成片版本归档。
3. 成本统计。
4. 项目复盘。

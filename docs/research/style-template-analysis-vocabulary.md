# 全局风格模板识别词汇库 MVP

本词汇库用于“上传漫剧风格截图 -> AI 识别 -> 自动生成风格模板”。它不是单纯堆关键词，而是把风格拆成可复用字段，后续会进入角色生图、关键帧生成和生视频提示词。

## 识别字段

1. 风格类型
- 国漫厚涂
- 写实漫剧
- 赛璐璐国漫
- 暗色电影国漫
- 水墨武侠
- 潮汕民俗奇幻
- 舞台仪式感
- 低饱和电影感

2. 线条特征
- 清晰轮廓线
- 粗细有变化的描线
- 低线条、靠光影塑形
- 毛笔感边缘
- 干净赛璐璐线
- 服饰纹样线条清晰

3. 色彩倾向
- 陶土红
- 暗金
- 靛青
- 墨黑
- 朱砂红
- 青绿色边缘光
- 低饱和暖色
- 高对比冷暖分离

4. 光影方式
- 侧逆光
- 金色舞台边缘光
- 鼓阵火光
- 巷口低照度
- 祠堂烛光
- 月光冷调
- 强轮廓剪影
- 背景暗、主体亮

5. 构图倾向
- 低机位仰拍
- 中近景英雄构图
- 竖屏主体居中
- 前景遮挡制造层次
- 队列纵深
- 鼓阵环形构图
- 强对角线动作

6. 人物渲染
- 脸谱边界清晰
- 五官稳定
- 头饰结构明确
- 服饰刺绣纹样可读
- 武器位置稳定
- 动作剪影明确
- 皮肤与妆容分层

7. 背景处理
- 潮汕祠堂
- 石板巷口
- 鼓阵舞台
- 烟雾和纸钱层次
- 背景虚化不抢主体
- 民俗符号点缀
- 暗部保留空间纵深

8. 质感关键词
- 高质量漫剧质感
- 电影级调色
- 细腻厚涂
- 干净线条
- 胶片颗粒
- 戏剧性边缘光
- 民俗仪式感

9. 负面约束

- 脸部崩坏

- 手指错误

- 武器变形

- 文字乱码

- 过度磨皮
- 现代服饰误入

## GPT Image 2 提示词组织原则

1. 用自然语言清楚描述画面，而不是碎片化关键词堆叠。
2. 每次生成只锁定一个核心任务，例如角色四视图、风格转换、关键帧。
3. 引用风格模板时要明确“参考哪些维度”，例如线条、色彩、光影、构图，而不是只说“参考这张图”。
4. 英歌题材必须显式约束脸谱、服饰、头饰、武器、动作身段和民俗场景符号。
5. AI 输出必须先作为候选资产，人工采纳后才能进入关键帧链路。

## 风格识别 Prompt 骨架

你是 AI 漫剧视觉导演和提示词设计师。请根据上传截图，识别它的可复用视觉风格。不要描述剧情，不要猜测人物身份，只分析画面语言。

输出以下字段：
- style_category
- visual_summary
- line_style
- color_palette
- lighting_style
- composition_style
- character_rendering
- background_rendering
- texture_keywords
- image_prompt_template
- video_prompt_template
- negative_prompt

要求：
- 字段必须能直接服务 AI 漫剧生图、生视频和关键帧生成。
- 优先使用稳定、可复用、可组合的视觉词。
- 避免“高级、好看、震撼”等空泛词。
- 必须补充英歌题材一致性约束：脸谱、服饰、头饰、武器、鼓阵、祠堂、巷口、队列、动作身段。
